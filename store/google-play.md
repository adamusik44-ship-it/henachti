## מה רק אתה יכול לעשות

1. **לפתוח חשבון מפתח.** https://play.google.com/console/signup , חשבון אישי, 25 דולר חד-פעמי, אימות זהות עם תעודה. האישור לוקח בדרך כלל כמה ימים. גוגל גם מבקשת לאמת שיש לך מכשיר אנדרואיד אמיתי, דרך אפליקציית Play Console בטלפון.
2. **לבחור אימייל ציבורי לתמיכה.** הוא מוצג לכולם בדף האפליקציה. מומלץ לפתוח כתובת ייעודית ולא להשתמש באישית.
3. **לגייס 12 בודקים.** חשבון אישי חדש חייב בדיקה סגורה: 12 אנשים עם חשבון גוגל, שמתקינים ומשאירים את האפליקציה 14 יום רצופים. בלי זה אין אישור לפרסום. הודעה מוכנה לשליחה בסוף המסמך.
4. **לצלם סרטון מסך קצר** להצהרת השירות הקדמי (פירוט למטה), ולהעלות אותו ליוטיוב כ"לא רשום".

כל השאר מוכן כאן. כשהחשבון פתוח ואתה מחובר אליו בדפדפן, אפשר לבקש ממני למלא את הטפסים.

**Foreground service permission** (Special use). להדביק באנגלית:

```
Ukshartem is a self-imposed app blocker for a daily religious practice (putting on tefillin).
After the user explicitly turns the lock on ("דרוך את המנעול"), a foreground service checks
UsageStatsManager about twice a second while the screen is on to see which app is in the
foreground, and shows the app's own lock screen over blocked apps until the user completes
the daily camera verification. The check has to run continuously for as long as the lock is
active, so it cannot be deferred or scheduled, and no other foreground service type describes
it. The service shows a persistent notification with the current state (locked, snoozed, open),
and the user can turn the lock off from the app's settings at any time the phone is open.
All processing is on the device; the app has no internet permission.
```

## הגרסה ב-Play לעומת הגרסה הישירה

הגרסה ל-Play רכה יותר בשתי נקודות, כי גוגל מסירה אפליקציות שחוסמות את ההסרה של עצמן:

- אין "הגנה מפני מחיקה" (מנהל מכשיר). חמישה מתגים במקום שישה.
- חלון ההסרה של המערכת תמיד פתוח, גם בזמן נעילה.

כל השאר זהה. הגרסה הישירה (קובץ ה-APK מהקישור) נשארת עם ההגנה המלאה.
מזהה החבילה ב-Play: `app.ukshartem`. הוא קבוע לתמיד מרגע ההעלאה הראשונה.

קודם אוספים 12 כתובות Gmail ומוסיפים אותן ב-Testing → Closed testing → Testers. אחרי שהגרסה מאושרת לבדיקה, Play Console נותן קישור הצטרפות. ההודעה:

```
היי, בניתי אפליקציה שנועלת את הטלפון בבוקר עד שמניחים תפילין, ואני צריך 12 בודקים כדי שגוגל תאשר אותה לחנות.
מה צריך ממך: להצטרף בקישור, להתקין מהחנות, ולהשאיר אותה מותקנת 14 יום. אם תפתח אותה פעם ביום זה עוד יותר טוב.
לא חייבים להפעיל את הנעילה. יש בפנים גם סידור מלא.
הקישור: [קישור ההצטרפות מ-Play Console]
תודה רבה!
```

אחרי 14 יום: Dashboard → Apply for production. גוגל שואלת כמה שאלות על הבדיקה (מה למדת, מה תיקנת), ואז בודקת את האפליקציה, בדרך כלל עד שבוע.
